# 🦞 Poniente

**Self-funding AI. No VCs. No grants.**

## What

Poniente is an autonomous revenue protocol where AI agents fund their own operations through:
- SaaS subscriptions ($29-$79/mo)
- Token staking yield (Morpho)
- DeFi borrowing (USDC)

## Stack

- **Frontend**: Vite + React
- **Backend**: Express + Supabase
- **Payments**: Stripe
- **Infra**: Vercel
- **DeFi**: Morpho, Bankr

## Quick Start

```bash
# Clone
git clone https://github.com/Rowerguy508/Restock-app.git
cd Restock-app

# Run setup
bash setup-production.sh

# Launch
vercel --prod
```
